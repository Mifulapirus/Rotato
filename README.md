# Rotato

### Spin. Smash. Repeat.

*A combat-style workshop robot built at [Asmbly](https://asmbly.org), controlled from your browser.*

🔗 **Project page:** [thehomelab.dev/projects/rotato](https://thehomelab.dev/projects/rotato)

## Firmware versions

| Folder | Status | Notes |
|---|---|---|
| [`Rotato 2026/`](Rotato%202026/) | Stable | Firmware for the 2026 robots (ESP32-C3 Super Mini). |
| [`Rotato 2027/`](Rotato%202027/) | In development | Firmware for the 2027 robot. Started as a copy of Rotato 2026. |

Each folder is a self-contained PlatformIO project. Open the folder you want in VS Code with the PlatformIO extension, then build and flash as described in that folder's README.
